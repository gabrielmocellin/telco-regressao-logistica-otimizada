# Projeto de Programação Não Linear — Previsão de *Churn* com Regressão Logística e Redução de Atributos

Este repositório contém a implementação computacional, os experimentos numéricos e o relatório em LaTeX desenvolvidos para a disciplina de **Programação Não Linear (UFPR / DMAT)**.

## Objetivo
Investigar a aplicação de métodos de otimização contínua irrestrita — **Método de Cauchy (Gradiente) com Busca Linear Exata** e **Método de Newton Puro** — na estimação de parâmetros e na **redução da quantidade de atributos** em modelos de Regressão Logística voltados à previsão de cancelamento (*Churn*) de $7.043$ clientes de telecomunicações (`telco.csv`), validando os resultados frente à biblioteca `scikit-learn`.
